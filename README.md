# Bank Management System

This is a full-stack Bank Management System developed as a final year project. It provides a user-friendly interface for banking operations such as:

- Account creation
- Balance inquiry
- Deposits and withdrawals
- Transaction history
- Admin management

## 🛠️ Technologies Used

### Frontend:
- HTML
- CSS
- JavaScript *(or React, if used)*

### Backend:
- MySQL *(or other database used)*
